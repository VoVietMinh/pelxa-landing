# Pelxa — Website (Node.js MVC)

> Content · Ads · Traffic — Global, Future Ready
> Marketing site for **pelxa.com**, built as a clean, SEO-friendly MVC app
> using Express, EJS and Tailwind CSS. No database — blog content lives
> in `/data/blog.json`.

---

## Stack

| Layer | Tech |
|-------|------|
| Runtime | Node.js 18+ |
| Server | Express 4 |
| Views | EJS + `express-ejs-layouts` |
| Styling | Tailwind CSS (compiled to `public/css/tailwind.css`) |
| i18n | English / Vietnamese (JSON dictionaries in `/locales`) |
| Data | JSON files (`/data/blog.json`) — no DB required |

## Run locally

### 1. Install dependencies

```bash
npm install
```

### 2. (Optional) Rebuild the CSS

The compiled `public/css/tailwind.css` is committed so the site runs out of
the box. If you change Tailwind classes in `views/` or tokens in
`tailwind.config.js`, rebuild it:

```bash
# One-shot, minified build
npm run build:css

# Or watch while developing
npm run watch:css
```

### 3. Start the server

```bash
npm start             # production
npm run dev           # auto-reload via nodemon
```

The site will be available at:

| Locale | URL |
|--------|-----|
| English | http://localhost:3000/en |
| Tiếng Việt | http://localhost:3000/vi |

`http://localhost:3000/` redirects to `/en`.

You can override the port via the `PORT` env var:

```bash
PORT=4000 npm start
```

## Routes

### English (`/en/...`)

| Route | Page |
|-------|------|
| `/en` | Home |
| `/en/solutions` | Solutions |
| `/en/partners` | Partners |
| `/en/resources` | Resources / Blog index |
| `/en/resources/:slug` | Blog post |
| `/en/about` | About |
| `/en/contact` | Contact |

### Vietnamese (`/vi/...`)

| Route | Page |
|-------|------|
| `/vi` | Trang chủ |
| `/vi/giai-phap` | Giải pháp |
| `/vi/doi-tac` | Đối tác |
| `/vi/tai-nguyen` | Tài nguyên / Blog |
| `/vi/tai-nguyen/:slug` | Bài blog |
| `/vi/ve-chung-toi` | Về chúng tôi |
| `/vi/lien-he` | Liên hệ |

### SEO

- `GET /sitemap.xml` — auto-generated from the route map + blog posts
- `GET /robots.txt` — references the sitemap

Each page emits:

- `<title>` and `meta description` from the locale dictionaries
- Canonical link tag
- `hreflang` alternates linking `/en` ↔ `/vi`
- Open Graph + Twitter card meta with `social-cover.png`
- JSON-LD `Organization` block

## Brand assets

All logo, favicon, app icon, social cover and pillar icons live in
`public/assets/` and come **directly from the branding kit** — they are
referenced as-is. No new logos are generated by this codebase.

If you replace them, keep the same filenames so the rest of the templates
keep working.

## i18n

Everything user-facing is keyed by `req.t.<page>.<key>`. To add or change
text, edit `locales/en.json` and `locales/vi.json` — both must define the
same keys. Routes pick a locale from the URL prefix (`/en` or `/vi`) so the
site is search-friendly per language.

## Blog content

Edit `data/blog.json`. Each post has:

```json
{
  "slug": "kebab-case-slug",
  "title": "...",
  "excerpt": "...",
  "category": "Monetization",
  "author": "Pelxa Insights",
  "date": "2026-04-22",
  "readMinutes": 6,
  "cover": "/assets/social-cover.png",
  "tags": ["monetization", "rpm"],
  "body": ["paragraph 1", "paragraph 2"]
}
```

Posts are split per locale (`en` / `vi`). The `slug` controls the URL.
